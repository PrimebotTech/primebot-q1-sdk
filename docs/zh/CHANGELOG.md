# 变更日志
本文件记录所有重要变更。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
并采用[语义化版本](https://semver.org/)。

## [v1.1.8.0] - 2026-11-09

**对应核心固件版本：Q1_v1.1.8.0**

### 新添加的功能
- 新增 IMU 惯导状态 、外挂算力板供电控制、停止音频播放 以及系统状态迁移（重启与关机）接口。
- 新增灯语逻辑说明。
- 播放表情和视频 接口新增 image 图片类型播放。
- 新增 Q1机型 的 Emotion 表情枚举与Motion 全身动作枚举。

### 对现有功能的变更
- 更新`接口说明.md`中的Q1机型 运控状态机切换逻辑图。
- 更新`接口说明.md`中关节限位参数。
- 更新`接口说明.md`中录音相关说明，录音示例新增 --channel-map 参数。
- 更正`接口说明.md`中音频文件播放接口支持的音频格式描述。
- 调整`接口说明.md`目录结构。

### 已经移除的功能
- 移除 `ShutdownTask`，由 `MigrateSystemState` 替代。
- 移除坐下动作与 Q1 不再支持的动作枚举。
- 移除 `AudioInfo` 中的 PCM 相关引用。

### 对 bug 的修复
- 修复文档中锚点链接跳转错误的问题。
- 修复文档格式与示例代码错误。
- 修复进行 arm 交叉编译时opencv报错问题。

## [v1.0.0.0] - 2026-10-10

Q1 SDK 接口文档与示例代码首个正式版本。
